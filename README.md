# Our Closet Designer 🚪👔👗

A little his-and-hers closet layout planner. Drag pieces (hanging rods, shelves,
drawers, shoe shelves, cubbies, a hamper) into closet sections, claim sections
for each person, and get:

- a to-scale drawing of the closet
- a fairness verdict on who got more hanging space
- a shopping list of pieces
- saved designs (stored in your browser) and a printable spec sheet

## Run it

It's one file — open `index.html` in a browser, or enable GitHub Pages on this
repo and visit the published URL.
